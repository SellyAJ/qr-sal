QR Sal 0.1.2

Detection, geometric sampling, QR format/data parsing, and Reed-Solomon
decoding are implemented in this project source. No WeChat, ZXing, jsQR, ZBar,
OpenCV or BarcodeDetector implementation is called by this scanner.

QR block-parameter table data was transcribed from Project Nayuki's
QR Code generator (https://www.nayuki.io/page/qr-code-generator-library).

Mathematical/format references consulted:
QR Code Model 2 (ISO/IEC 18004); DENSO WAVE QR version documentation;
ZXing's Apache-2.0-licensed format-reader and Reed-Solomon reference code.
The decoder uses its own Berlekamp-Massey implementation and image detector.

PDF.js (Mozilla, Apache-2.0) is used only to render/open PDF files.
It does not detect or decode QR codes. The static demo ships its license at vendor/PDFJS-LICENSE.txt.
The test fixtures are independently generated with Python qrcode 8.2;
the fixture generator is not shipped as a runtime decoder.
